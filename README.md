## ImageKit photo storage

Uploads are sent directly from the browser to ImageKit using short-lived upload authentication generated by the server. The private API key is only read by server routes. The gallery reads the uploaded images and their captions from the `wedding-gallery` folder, so the same photos are available across devices.

1. In ImageKit, copy the account's public and private API keys from **Developer options**.
2. Copy `.env.example` to `.env.local` and fill in both keys. Keep `.env.local` private, then restart the development server.
3. In ImageKit's **Media Library settings → Custom Metadata**, create these fields (the API names must match):
   - `photoTitle` — Text, maximum length 100
   - `photoCaption` — Textarea, maximum length 500
4. Upload a photo from the site. ImageKit creates or uses the `wedding-gallery` folder, and the gallery lists image assets from that folder.

The custom metadata fields are needed because ImageKit requires metadata fields to exist before uploads can attach title and caption values.

## Deploy on Vercel

1. Import this GitHub repository into a new Vercel project. Vercel detects Next.js automatically.
2. Add `IMAGEKIT_PUBLIC_KEY` and `IMAGEKIT_PRIVATE_KEY` in the Vercel project's Environment Variables settings. Enable them for **Production**; enable **Preview** only if preview deployments should upload into the same wedding gallery.
3. Keep `IMAGEKIT_PRIVATE_KEY` server-only. Do not rename it with a `NEXT_PUBLIC_` prefix.
4. Deploy the project. If you add or change environment variables later, create a new deployment for them to take effect.

See [Vercel's environment variable guide](https://vercel.com/docs/environment-variables/managing-environment-variables) for current setup details.
